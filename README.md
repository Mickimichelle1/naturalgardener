## 🔧 Quick Setup

### 1. Add Google Analytics
In `index.html`, replace `G-XXXXXXXXXX` with your GA4 Measurement ID:
```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-YOUR_ID"></script>
```

### 2. Add Google AdSense
Replace `ca-pub-XXXXXXXXXX` with your Publisher ID throughout the file:
```html
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-YOUR_ID"></script>
```

### 3. Deploy
```bash
git add .
git commit -m "Add analytics and AdSense IDs"
git push origin main
```

Site updates automatically! ✨
